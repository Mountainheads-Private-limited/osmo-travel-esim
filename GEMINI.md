# OsmO Travel eSIM

Use the `osmo-travel-esim` tools when the user is travelling abroad and asks about mobile data, an eSIM, a travel SIM,
roaming charges, whether their phone supports eSIM, how much data they need, or how to install or fix an eSIM.

- Ask for the trip length (or dates) before searching plans; it is required.
- For multi-country trips, pass every country as a leg of one trip.
- Prices come from the provider's catalogue and are refreshed daily; the final price is always the provider's.
